### 📱 Lembretes de Aniversários

O **Lembretes de Aniversários** é um aplicativo móvel desenvolvido para ajudar você a gerenciar datas importantes e compartilhar mensagens personalizadas de forma rápida e prática. Crie uma lista organizada com nome, foto e templates de mensagens prontos para envio direto pelo WhatsApp. 

Com foco total na sua privacidade, o aplicativo não utiliza servidores de terceiros: todos os seus dados são sincronizados de forma segura diretamente na sua própria conta do Google Drive. 

### ✨ Principais Funcionalidades

* **Lista Personalizada:** Cadastre aniversários, eventos e datas comemorativas adicionando o nome e a foto da pessoa.
* **Mensagens Prontas para WhatsApp:** Vincule mensagens personalizadas a cada evento. Na data cadastrada, use o modelo integrado para abrir o WhatsApp diretamente com o texto pronto para envio.
* **Notificações Inteligentes:** Receba alertas no seu dispositivo na data e hora cadastradas para nunca mais esquecer de parabenizar alguém.
* **Sincronização Multi-Dispositivo (Android):** Acesse seus lembretes em múltiplos aparelhos Android. Seus dados são salvos e atualizados automaticamente.

### 🔒 Segurança e Privacidade Própria

O aplicativo adota a arquitetura de **Zero Servidor Externo**. Isso garante o controle total dos dados na mão do usuário: 

* **Google Login:** Utilizado estritamente para autenticação segura e identificação do usuário.
* **Nuvem Própria via Google Drive:** O app solicita acesso apenas para ler e escrever os arquivos de configuração e banco de dados no seu Google Drive (utilizando escopos restritos). Seus lembretes e fotos pertencem apenas a você.
* **Sem Rastreamento:** O aplicativo **não coleta** dados de localização, **não exige** biometria, é **100% livre de anúncios** e não possui compras internas.

### 🛠️ Tecnologias Utilizadas

* **Plataforma:** Android
* **Autenticação:** Google OAuth 2.0
* **Armazenamento e Sincronização:** Google Drive API
* **Notificações:** Android Notification System / WorkManager
